# yomiyasu の語の一覧の正規表現。1行に「名前<TAB>正規表現」。名前は指摘に出るので、使う語を「→」のあとに書く（40 字まで）。
# 書き方と、指摘が出たときの直し方は docs/writing.md にまとめている。
# 漢字1字の語を、熟語と数の後ろ（1段、2段）を除いて当てる。後読みは直前の1字だけを見るので、熟語は鍵の直前の字（公開鍵なら「開」）で除く。
# 上限のない繰り返し（* と +）と、取り込む組の ( ) は使えない。

# ソフトウェアや文書の version は「バージョン」。出版物の「第2版」や「日本語版」、作品の種類の「劇場版」には当てない。
版→バージョン	(?<![出初再改図木製凸凹石場])版(?![画権数])

# 処理の順に並んだ一つ一つは「ステップ」、期間で区切った一つ一つは「フェーズ」。画質の並びは「画質の段階」。
# 「1段ずつ」「2段重ねる」のような数の段と、「手段」「段階」「前段」には当てない。
段→ステップかフェーズ	(?<![0-9０-９一二三四五何数多手階値普格算特別前上中下])段(?![階落差取])

# 番組名に付く記号や、画面で付ける目印は「マーク」。「矢印」「目印」には当てない。
印→マーク	(?<![矢目調封刻実押])印(?![刷象鑑])

# DB や表の column は「カラム」。「文字列」「バイト列」のような sequence には当てない。
列→カラム	(?<![行系並直配序陳整羅字])(?<!バイト)(?<!ビット)(?<!パケット)列(?![挙車])

# 照合や索引に使う key は「キー」。暗号の「公開鍵」「秘密鍵」「暗号鍵」「署名鍵」「共通鍵」には当てない。
鍵→キー	(?<![開密号名合通有])鍵(?![盤])

# 時間の範囲は「ウィンドウ」。画面に重ねて出す確認の画面は「ダイアログ」。
窓→ウィンドウかダイアログ	窓(?![口])

# 要らないデータを消すのは「破棄する」。読まずに進めるのは「読み飛ばす」。「切り捨て」「使い捨て」には当てない。
捨て→破棄	(?<!切り)(?<!使い)捨て

# データの一まとまりは「チャンク」。「一塊」には当てない。
塊→チャンク	(?<![一土金氷鉄岩])塊

# 誤りや設定を正すのは「修正する」。「やり直す」「読み直す」のような「〜し直す」には当てず、名詞と「直す」だけに当てる。
直し→修正	(?:(?<=[のをがはもで、。（「 ])|^)直し

# DB のテーブル、対応表、文書の中の表は「テーブル」。「番組表」「表示」「表現」「代表」「表す」「表れる」には当てない。
表→テーブル	(?<![一-龥])表(?![示現記明情面すさしせれ一-龥])

# 積み重ねた PR やブランチは「スタック」。「積み残し」「積み重ね」「見積もり」には当てない。
積み→スタック	(?<!見)積み(?![残重上込立])

# git の branch は「ブランチ」。UNION ALL や条件の分かれ目は「分岐」か「サブクエリ」。「枝番」（局の番号の枝番）と「枝豆」「小枝」には当てない。
枝→ブランチか分岐	(?<![小])枝(?![番豆])

# 文書や設定ファイルの区切りは「セクション」。「季節」「調節」「節約」のような熟語には当てない。
節→セクション	(?<![一-龥])節(?![一-龥])

# 利用者へ送るものは「通知」。「お知らせ」と、動詞の形（flag.txt にある）には当てない。
知らせ→通知	(?<!お)知らせ(?!る|ます|て|た|ない)

# 要求や操作を受け付けないのは「拒否する」。「判断」「中断」「切断」のような熟語には当てない。「断られ」は flag.txt で当てる。
断る→拒否する	(?<![一-龥])断(?=[るりっ]|ら(?!れ))
