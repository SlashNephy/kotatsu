# yomiyasu の語の一覧。Kotatsu の文章（画面の文言、ドキュメント、コードのコメント、コミット、Issue と PR）で使わない語。
# 書き方と、指摘が出たときの直し方は docs/writing.md にまとめている。
# 1行に「使わない語<TAB>使う語」か「使わない語」。区切りはタブで、空白では区切れない。行末に # を書いても注釈にならない。
# 当たった行には、yomiyasu の lint が project_term の指摘を出し、使う語を添える。
# 使う語は、使わない語と同じものを指すときに、そのまま替えてよい語。場面で替える語が変わるものは、その語の上の注釈に書く。
# 漢字1字の語は、ほかの語の中でも当たるので、flag-patterns.txt に前後の字を除いて書く。

# ---- 和語の連用形と動詞 ----

確かめ	確認

# 画面やサーバーが利用者へ送るものは「通知する」。人に事情を伝える文（Issue や PR）では「伝える」。
# 「お知らせ」（番組のジャンル名など）には当たらないよう、動詞の形だけを並べている。
知らせる	通知する
知らせます	通知します
知らせて	通知して
知らせた	通知した
知らせない	通知しない

# 複製は「コピーする」。元を残さずに移すのは「移す」、移行の処理は「移行する」。
写し	コピー
写す	コピーする
写さ	コピーさ

# データを形式に合わせて外へ出すのは「エクスポートする」。バックアップの作成は「バックアップする」、ログやファイルへの書き込みは「出力する」。
書き出し	エクスポート
書き出す	エクスポートする

比べ	比較

# 原因や様子を探るのは「調査する」。値や設定を見て確かめるのは「確認する」、外から得るのは「取得する」。
調べ	調査

# 外から取り直すのは「再取得する」。DB の行やロックを取り直すのは「取得し直す」。
取り直	再取得

# 設定や状態を残すのは「保存する」。結果を一時的に持つのは「キャッシュする」。React Compiler が値を覚えるのは「メモ化する」。
覚え	保存

試し直	再試行
伏せ	マスク
溜め	バッファ
照らし合わせ	照合
突き合わせ	照合

測り	計測
測る	計測する
測って	計測して
測った	計測した

# ストリームや通知を送るのは「配信する」。ID や番号を決めて渡すのは「割り当てる」。バイナリやパッケージを公開するのは「配布する」。
配る	配信する
配ります	配信します
配り	配信し
配っ	配信し
配ら	配信し

# HTTP の要求を別のサーバーへ渡すのは「プロキシする」。ストリームを受け手へ渡すのは「配信する」。
# 衛星の「中継器」（トランスポンダー）は ARIB の用語なので当てない。
中継する	プロキシする
中継し	プロキシし

# 同じ回の放送をまとめるのは「まとめる」か「グループにする」。複数のサーバーを一つに扱うのは「集約する」。
束ね

# 時間の間隔は「間隔」。値の細かさは「単位」か「粒度」。
刻み

# DB や API から探して得るのは「取得する」か「検索する」。数を減らすのは「差し引く」。
を引く
で引く

# ---- 名詞 ----

中身	内容

# テスト用に立てる偽物のサーバーは「モックの」。
偽の	モックの

副題	サブタイトル

# ファイルの保存先は「保存先」。設定や生成物の場所は「場所」か「ディレクトリ」。
置き場	保存先

版数	バージョン
索引	インデックス

# 並びや文字列の初めは「の先頭」。パスや名前の前に付ける決まった文字列は「のプレフィックス」。
の頭	の先頭

試しの	プローブの

# 判定に使う前ぶれの事象は「兆候」。
兆し	兆候

# データを得た先は「ソース」か「取得元」。記録した理由は「根拠」。
出どころ	ソース

# HTTP の URL は「エンドポイント」。プログラムや関数の起点（main パッケージなど）は「エントリーポイント」。画面のリンクやメニューは「リンク」か「メニュー」。
入口	エンドポイント
入り口	エンドポイント

# ---- 「〜器」の訳語 ----

描画器	レンダラー
復号器	デコーダー
符号化器	エンコーダー
解析器	パーサー
認証器	オーセンティケーター
